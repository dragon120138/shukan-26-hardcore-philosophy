# 书刊26 硬核心智逻辑与可计算性的哲学史

> 学术·政治经济

## 关于本书

发展型国家的政治经济学研究通常以“增长奇迹”为前提，本书讨论的恰恰是奇迹退潮之后的部分。当高速增长不再，治理难题从做大蛋糕切换为另一组问题：合法性来源转向何处、社会稳定在低增长下如何维持、政策工具箱里哪些还有效。全书以东亚与拉美经验为对照，围绕合法性叙事重建、利益冲突的制度化消化、产业与宏观政策的再定位三组选择展开，机制分析配以跨国数据与历史案例。

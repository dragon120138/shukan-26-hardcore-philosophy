# 【书刊26】 硬核心智逻辑与可计算性的哲学史

> 学术·哲学史

## 关于本书

不走寻常路的哲学史：不按人物排列，按问题推进——心智是什么、逻辑如何形式化、可计算性边界在哪里。从弗雷格概念文字到哥德尔不完备定理，从图灵机到停机问题，穿过维也纳学派、罗素悖论与希尔伯特纲领的崩塌。每个哲学断言都配数学骨架：不是讲故事，是把论证推给你看。全部论证可核验，全部历史有出处。
